Every rendered example below uses the real .hs-* / .cf / .acc-* classes from components.css, plain HTML — no React. Each cell's caption is the exact class string on the markup above it. Hover, click, and tab into examples to see live hover/pressed/focus states (defined in the CSS, not screenshotted here).

Reading this gallery: "state" rows show what the CSS defines a modifier class for (e.g. .is-on, [disabled]). Where Bento's own Confluence page documents no interactive states at all (see README "Authored vs inferred"), the hover/pressed/focus you see here still fires — it comes from the shared focus-ring and button-family rules in components-ext.css, not from a per-component spec.
